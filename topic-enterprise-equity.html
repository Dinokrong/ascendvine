Enterprise Value & Equity Value

Enterprise Value and Equity Value are two lenses for measuring a company's worth. Understanding the difference — and how to move between them — is essential for every valuation and deal analysis.

Equity Value (Market Capitalization)

Equity Value represents the value of the company attributable to equity shareholders only.

Basic Equity Value = Share Price × Basic Shares Outstanding

Fully Diluted Equity Value = Share Price × Diluted Shares Outstanding

Diluted shares include the dilutive effect of in-the-money options, warrants, and convertible securities, calculated via the Treasury Stock Method (TSM).

Treasury Stock Method (TSM): Assume all in-the-money options are exercised. The proceeds received are used to repurchase shares at the current price. Net new shares = Shares issued − Shares repurchased.

Enterprise Value

Enterprise Value (EV) represents the total value of the business to all capital providers — debt holders, preferred shareholders, minority interest holders, and equity shareholders.

EV = Equity Value + Debt + Preferred Stock + Minority Interest − Cash & Cash Equivalents

Why Each Item Is Added or Subtracted

  • + Debt: An acquirer must repay or assume the debt — it's part of the acquisition cost
  • + Preferred Stock: Has a senior claim; must be satisfied before common equity
  • + Minority Interest: The company consolidates 100% of subsidiaries it controls (>50%), so EV must reflect the portion not owned by the parent
  • − Cash: An acquirer effectively gets the cash — it offsets the purchase price

Enterprise Value vs. Equity Value Multiples

You must match the value metric to the financial metric — use Enterprise Value with metrics that belong to all capital providers (before interest), and Equity Value with metrics that belong to shareholders (after interest).

  • EV/Revenue, EV/EBITDA, EV/EBIT, EV/NOPAT — these are pre-debt metrics
  • P/E (Equity Value / Net Income), P/Book — these are post-debt (equity) metrics
A common mistake: using Net Income with Enterprise Value. Net Income is after interest expense, so it belongs to equity holders only — pair it with Equity Value (P/E ratio).

Moving from Equity Value to Enterprise Value

The "bridge" between Equity Value and Enterprise Value is the net debt position (Debt − Cash). If a company has more cash than debt, it has "net cash" and EV < Equity Value. If it has more debt, EV > Equity Value.

Diluted Shares Worked Example

Company has 100 shares at $10, and 10 in-the-money options with a $5 strike.

  • Options exercise → company receives $50 in proceeds (10 × $5)
  • Company uses $50 to repurchase 5 shares at $10 each
  • Net new shares = 10 − 5 = 5
  • Diluted shares = 105 → Fully Diluted Equity Value = 105 × $10 = $1,050
